# Android-приложение кооператива

Приложение — это Trusted Web Activity (TWA): полноэкранный Chrome, который
открывает сайт кооператива как приложение. Собирается утилитой Google
[Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap) из PWA-манифеста
сайта (`/manifest.webmanifest`, `app/main.py:web_manifest`). Отдельного кода
приложения нет: всё, что меняется на сайте, сразу видно в приложении, APK
пересобирается только при смене названия, иконки или версии.

**У каждого кооператива — своё приложение**: свой домен, своё имя пакета,
свой ключ подписи, своя карточка в магазине.

## Push-уведомления

Работают через те же web-push, что и на сайте (`app/webpush.py`, ключи VAPID
в БД). В приложении включена делегация уведомлений (`enableNotifications`):
уведомления показываются от имени приложения, с его иконкой. На Android 13+
система спрашивает разрешение на уведомления при первом запуске; дальше
член кооператива включает уведомления как на сайте — кнопкой в профиле.

## Что нужно от вас

На каждый кооператив:

1. **Имя пакета** — латиницей, через точки, например `ru.gmvoshod.app`.
   После публикации поменять его нельзя (это будет другое приложение).
2. **Аккаунт разработчика в магазине** (один на все кооперативы, если
   публикуете от себя; или у каждого кооператива свой — если от его имени):
   - **RuStore** (`console.rustore.ru`) — регистрация бесплатная, нужна
     верификация (физлицо через Госуслуги, ИП или юрлицо). Принимает APK.
   - **Google Play** (`play.google.com/console`) — разовый взнос $25. У новых
     личных аккаунтов перед публикацией обязателен закрытый тест (не менее
     12 тестировщиков в течение 14 дней). Принимает только AAB.
3. **Компьютер для сборки** с Node.js 18+. Bubblewrap при первом запуске сам
   скачает JDK 17 и Android SDK (около 1 ГБ).
4. **Ключ подписи и его хранение.** Ключ создаётся один раз командой
   `keytool` (шаг 2 сборки ниже) с двумя паролями. **Ключ и пароли —
   сделать резервную копию (не в git, не на сервер сайта).** Потеряете ключ —
   не сможете выпускать обновления этого приложения, только новое под другим
   именем пакета.
5. **Проверить текст политики конфиденциальности** — страница `/privacy`
   (`app/templates/privacy.html`), адрес обязателен в карточке приложения в
   обоих магазинах. Реквизиты подставляются из карточки кооператива — в ней
   должны быть заполнены полное название, ИНН, ОГРН, юридический адрес и email.
6. **Материалы для карточки магазина:** краткое и полное описание, не менее
   двух скриншотов телефона; для Google Play — ещё баннер 1024×500, анкета
   возрастного рейтинга и форма «Безопасность данных» (сведения — те же, что
   на странице `/privacy`).

## Сборка

Сначала задеплойте сайт с манифестом и иконками и проверьте, что открывается
`https://<домен>/manifest.webmanifest`.

```bash
# 1. Проект приложения — в отдельном каталоге вне репозитория
python3 scripts/make_twa_manifest.py https://гм-восход.рф ru.gmvoshod.app
#   → ~/coop-android/xn----dtbbg1boax0b.xn--p1ai/twa-manifest.json
cd ~/coop-android/xn----dtbbg1boax0b.xn--p1ai

# 2. Ключ подписи (один раз; keytool — из JDK 17+; спросит два пароля)
keytool -genkeypair -keystore android.keystore -alias android \
    -keyalg RSA -keysize 2048 -validity 10000 \
    -dname "CN=ГМ Восход, O=ГМ Восход, C=RU"

# 3. Сборка: при первом запуске спросит, сгенерировать ли Android-проект
#    (ответить «да»), и пароли ключа
npx @bubblewrap/cli@1.27.0 build
#   → app-release-signed.apk (RuStore, установка вручную) и app-release-bundle.aab (Google Play)

# 4. SHA-256 отпечаток ключа — строка «SHA256:» в выводе
keytool -list -v -keystore android.keystore -alias android
```

## Подтверждение домена (assetlinks)

Без него приложение откроет сайт с адресной строкой браузера сверху. В `.env`
сайта этого кооператива:

```
ANDROID_APP_PACKAGE=ru.gmvoshod.app
ANDROID_APP_SHA256=AA:BB:…:FF
```

Отпечатков может быть несколько, через запятую. В Google Play обычно включена
подпись приложений Google (Play App Signing) — тогда добавьте и отпечаток из
Play Console → «Целостность приложения» → «Подпись приложения». Перезапустите
сайт и проверьте `https://<домен>/.well-known/assetlinks.json`.

Проверка на телефоне: установите APK (`adb install app-release-signed.apk`
или файлом) — приложение должно открыться без адресной строки, на весь экран.

## Новая версия приложения

Нужна только при смене названия, иконок или цветов (содержимое сайта
обновляется само):

```bash
cd ~/coop-android/<домен>
npx @bubblewrap/cli@1.27.0 update --appVersionName=1.0.1
npx @bubblewrap/cli@1.27.0 build
```

`appVersionCode` Bubblewrap увеличивает сам. Магазины принимают обновление,
только если оно подписано тем же ключом.

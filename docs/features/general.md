# Общее: главная, дашборд, язык, тема, роли

[← К оглавлению](../../README.md)

## Общее
- **Главная страница** (`/`, `app/main.py: index()`) — общедоступна и
  одинакова для анонимного посетителя и вошедшего (никаких редиректов по
  роли: раньше `/` уводило анонимного на `/auth/login`, вошедшего на
  `/dashboard` — председателю/правлению для дашборда теперь отдельный
  пункт меню). Показывает новостную ленту кооператива (`News`,
  редактируется правлением через `/news`, доступ по
  `roles_required(RoleEnum.BOARD)`) и компактное превью видеонаблюдения
  (по одному смонтированному кадру на регистратор, ссылка «Все камеры» на
  полную `/surveillance/`). Форма входа — не здесь, а всегда доступным
  дропдауном «Войти» в шапке (виден на любой странице для анонимного,
  см. `base.html`, `auth/_login_form.html`); `/auth/login` как отдельная
  страница осталась — нужна как цель редиректа `login_required` и для
  прямых ссылок вроде «Забыли пароль?». После входа — не на дашборд/«мои
  гаражи», а туда же, где стоял дропдаун (или куда вёл `next`, если это
  был редирект с защищённой страницы) — см. `login_next_url` в
  `app/__init__.py`. Новостная лента показывает последние 5 записей.
  Текст — в упрощённой markdown-разметке (**жирный**, *курсив*,
  `[ссылка](url)`, списки через «- », заголовок «### »; панель кнопок над
  полем ввода в форме `/news/new`, `/news/<id>/edit`) и рендерится в
  безопасный HTML через `bleach` (`app/news_format.py`). Можно прикреплять
  фото и файлы (`NewsAttachment`, множественная загрузка) — показываются
  отдельной галереей под текстом; либо **вставлять картинку прямо в текст**
  кнопкой с камерой в панели — загружается по AJAX сразу же (POST
  `/news/attachments/upload`, ещё до сохранения самой статьи) и
  добавляется в место курсора как `![](url)`, картинки, вставленные так,
  в отдельную галерею не дублируются (см. `NewsAttachment.is_inline`); на
  ленте на главной — короткое текстовое превью (400 знаков, без разметки)
  со ссылкой «Читать дальше» на полную страницу `/news/<id>` (тоже
  публичную) для длинных новостей, полностью отрендеренная новость сразу —
  для коротких; фото показываются превью-миниатюрами прямо в ленте,
  остальные файлы — списком ссылок на полной странице
- **Переключатель языка** — выпадающее меню с флагом текущего языка на
  кнопке (🇷🇺/🇬🇧, эмодзи, без внешних иконочных шрифтов), в каждом пункте
  меню — флаг + название языка
- **Переключатель темы** — одна кнопка-пиктограмма (не выпадающее меню,
  тем всего две): показывает иконку той темы, в которую переключит клик
  (луна на светлой теме — переключить на тёмную, и наоборот)
- **Дашборд** (`/dashboard`, правление/бухгалтер/председатель):
  - **Баланс кооператива** — сумма фактических балансов всех расчётных
    счетов (`BankAccount.balance`, вносится вручную в реквизитах
    кооператива), считается динамически при каждом заходе. Это НЕ то же
    самое, что сумма ожидаемых поступлений по лицевым счетам членов
    (сколько кооперативу должны/переплатили) — тот показатель отдельно
    доступен как `accounting.receivables_balance()`, но на дашборд не
    выведен (нетто по всем счетам сразу, включая переплаты, — менее
    наглядно, чем прямая сумма долга ниже). Плашка — ссылка на
    `/finance/bank-accounts`
  - **Долги перед кооперативом** — сумма ОТРИЦАТЕЛЬНЫХ балансов и число
    счетов с долгом по активным лицевым счетам членов (взносы/налог/пеня
    вместе; переплаченные счета в сумму не подмешиваются, в отличие от
    `receivables_balance()`), ссылка на общий список счетов. Две
    агрегатные `GROUP BY`-выборки, не цикл `balance()` по каждому счёту
  - Плашки **«Гаражей»** и **«Людей в базе»** — тоже ссылки, на
    `/garages/` и `/persons/`
  - **Требует внимания** — ожидающие одобрения изменения анкетных данных
    (только председателю), открытые голосования без вашего бюллетеня,
    предложения членов кооператива, ждущие решения правления — те же
    счётчики, что уже считаются для бейджей в шапке сайта, без лишних
    запросов; блок не показывается, если ждать нечего
  - **Недавняя активность** — последние 8 записей журнала аудита
    (`AuditLog`), ссылка на полный журнал (`/governance/audit-log`)
- **Локализация** — русский/английский, переключатель в шапке (простой
  словарь `app/i18n.py`, без внешних зависимостей) — выпадающее меню с
  флагом; даты и суммы везде через
  `fmt_date()`/`fmt2()`, а не голым ISO/числом. Дробные числа выводятся с
  запятой для ru (точкой для en) — и вводятся обратно тем же способом:
  `parse_decimal()`/`parse_optional_decimal()` принимают и точку, и
  запятую как разделитель дробной части (плюс распознают группировку
  тысяч при копипасте), поля с суммами/площадями/коэффициентами —
  `type="text" inputmode="decimal"`, а не нативный `type="number"`
  (последний молча блокирует запятую в зависимости от языка браузера, не
  локали сайта)
- **Тема** — светлая/тёмная, хранится в сессии, переключается одной
  кнопкой-пиктограммой
- **Поиск в длинных списках выбора** — селекты с потенциально большим числом
  вариантов (собственники/контакты гаража, привязка учётной записи к
  человеку, секретарь/председательствующий на собрании, поставщик
  электроэнергии из контрагентов и т.п.) превращены в текстовое поле с
  выпадающим списком, отфильтрованным по вводу
  (`data-searchable` в шаблоне + один общий JS-компонент в `base.html`, без
  внешних библиотек — работает и для полей, добавляемых на лету, например
  строк собственников гаража)
- **Ссылки «Назад»** (`data-back-link`, общий скрипт в `base.html`:
  `rememberBackTarget`/`initBackLinks`) ведут туда, откуда реально пришли
  на страницу (вместе с фильтром/поиском в адресе), а не в жёстко
  прописанный раздел: адрес предыдущей страницы сайта запоминается в
  `sessionStorage` по pathname текущей — переживает перезагрузку после
  POST и AJAX-подмену содержимого. Исходный `href` — запасной вариант при
  заходе по прямой ссылке; если возврат ведёт не туда, надпись меняется на
  «← Назад». Переход по самой ссылке «Назад», кнопки браузера, вкладки
  (`?tab=`) той же страницы и соседние гаражи (`data-back-inherit`) адрес
  возврата не перезаписывают. Есть на карточках (человек, гараж, контрагент,
  голосование, тема форума, годовой отчёт, письмо почты и т.п.)
- **Человек ↔ гаражи** — в карточке человека блок «Гаражи» (собственник —
  с долей, лицо для связи — с отношением) со ссылками на гаражи; в
  карточке гаража собственники/контакты — ссылки на карточки людей
  (правлению — все, рядовому члену — на себя)
- **Роли и доступ** — рядовой член видит только свои данные (по привязке
  учётной записи к `Person` через владение гаражом или через сам `Person`);
  правление/бухгалтер — все данные; председатель — дополнительно учётные
  записи и правка чужих ошибок (последнее показание счётчика). Списки
  «Гаражи» и «Люди» (`/garages`, `/persons`) и карточка конкретного гаража
  или человека серверно проверяют доступ (не только скрывают пункт меню) —
  рядовой член не может открыть чужой гараж или чужую карточку по прямой
  ссылке
